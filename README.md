# ArduPilot — локальная сборка SpeedyBee F405 V4

Репозиторий подготовлен для загрузки исходников пользовательской прошивки ArduPilot из WSL. **Это не полный слепок исходников и не готовая прошивка.**

Локальное дерево, согласно диагностике 20.11.2026: `~/jtzero-ardupilot`, ветка `jtzero/custom-osd`, базовый коммит `dbe7921` (`ArduPilot 4.7.1`). Исходные изменения локального дерева пока не были экспортированы и поэтому не включены в этот репозиторий.

Проверенное назначение PWM по локальному `libraries/AP_HAL_ChibiOS/hwdef/speedybeef4v4/hwdef.dat`:

- PWM1–4: PB6, PB7, PB0, PB1 (M1–M4)
- PWM5–8: PC8, PC9, PB10, PA15 (M5–M8)
- PWM9: PA8 (M9/LED)

Физическая площадка S9 требует отдельной проверки электрической схемы. Не перепрошивайте FC по данному README.
